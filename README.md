##　　　　　　      拓殖大学紹介☺️
1. *拓殖大学*とは？
拓殖大学とは1900年、桂太郎により台湾教会学校として設立された大学です。
1. 建学の理念
たくしょくだいがくの建学の理念は**積極進種**の気概とあらゆる民族から敬慕されるに値する教養と品格を具えた有為の人材の育成*＊とされています。
